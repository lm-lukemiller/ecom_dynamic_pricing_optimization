# Open the dashboard without a terminal

1. In this repository, click **Code**, then **Codespaces**.
2. Click **Create codespace on main**. Allow a few minutes for the first setup.
3. The dashboard opens automatically. If your browser blocks the new tab, open **Ports** in the Codespace and click the globe beside **8501**.

To return later, open your existing Codespace from the same menu. The app restarts automatically.

This is a demonstration. The repository does not include trained models or the original dataset, so predictions use the author's demo fallback and some charts use synthetic or fixed example results. It is not connected to company data.

Keep forwarded ports private. Stop the Codespace when finished to avoid using more of your GitHub Codespaces allowance.
